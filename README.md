# حساب کارگاه قارچ — پروژه اندروید (APK واقعی)

این پوشه یک پروژه‌ی کامل Android Studio است که برنامه‌ی وب "حساب کارگاه قارچ" را داخل یک WebView بومی
(native) قرار می‌دهد. نتیجه یک فایل **APK واقعی** است که مثل هر اپلیکیشن دیگر نصب می‌شود، آیکون
مستقل دارد و **کاملاً آفلاین** کار می‌کند (بدون نیاز به اینترنت، بدون نیاز به مرورگر).

## روش ۱ (پیشنهادی، بدون نیاز به کامپیوتر قوی) — بیلد خودکار با GitHub Actions

1. یک ریپازیتوری جدید در GitHub بسازید (مثلاً به نام `mushroom-accounting-app`).
2. تمام فایل‌های این پوشه را در همان ریپازیتوری آپلود/پوش کنید (ساختار پوشه‌ها را دست نخورده نگه دارید).
3. به تب **Actions** ریپازیتوری بروید. یک ورک‌فلو به نام «Build APK» به‌صورت خودکار اجرا می‌شود
   (چون در فایل `.github/workflows/build-apk.yml` تعریف شده است).
4. چند دقیقه صبر کنید تا اجرا تمام شود (علامت سبز ✅).
5. روی همان اجرا (run) کلیک کنید، پایین صفحه بخش **Artifacts** را ببینید و فایل
   `mushroom-accounting-apk` را دانلود کنید. داخلش یک فایل `.apk` است.
6. آن فایل را روی گوشی اندروید منتقل کنید و نصب کنید (ممکن است لازم باشد گزینه‌ی
   «نصب از منابع ناشناس» را در تنظیمات گوشی فعال کنید، چون از گوگل‌پلی نیامده).

این دقیقاً همان روشی است که برای پروژه‌ی دستیار صوتی فارسی قبلی هم استفاده شد، چون این محیط
(چت Claude) خودش Android SDK و اتصال اینترنت لازم برای بیلد را ندارد؛ اما GitHub Actions
این کار را روی سرورهای گوگل/گیت‌هاب انجام می‌دهد.

## روش ۲ — بیلد مستقیم با Android Studio روی کامپیوتر خودتان

1. [Android Studio](https://developer.android.com/studio) را نصب کنید.
2. گزینه‌ی Open را بزنید و همین پوشه (`MushroomAccountingApp`) را انتخاب کنید.
3. صبر کنید Gradle Sync تمام شود (نیاز به اینترنت دارد تا کتابخانه‌ها دانلود شوند).
4. از منو: `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
5. فایل خروجی در مسیر `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## نکات مهم

- برنامه هیچ مجوز اینترنتی (`INTERNET`) ندارد؛ یعنی حتی اگر بخواهد هم نمی‌تواند به اینترنت وصل شود.
- تمام اطلاعات (کارگران، کارخانه‌ها، کار روزانه، کسورات، تسویه‌حساب) با `localStorage` داخل
  حافظه‌ی خود اپ روی گوشی ذخیره می‌شود.
- برای پشتیبان‌گیری، از همان دکمه‌ی «دانلود فایل پشتیبان» داخل تب تنظیمات برنامه استفاده کنید.

## نسخه‌ی release (امضاشده) برای انتشار در گوگل‌پلی

یک کلید امضا (keystore) واقعی از قبل برای شما ساخته و داخل پروژه (`app/release.keystore`) قرار
داده شده است. رمزهای عبور آن در فایل `keystore.properties` (کنار همین README) نوشته شده:

- **نام فایل کیستور:** `release.keystore`
- **Alias:** `mushroom-release`
- **رمز عبور:** داخل `keystore.properties` نگاه کنید

⚠️ **این دو فایل (`release.keystore` و `keystore.properties`) کاملاً محرمانه هستند.** آن‌ها را
جایی برای کسی نفرستید و در `.gitignore` هم قرار گرفته‌اند تا اگر پروژه را در GitHub پابلیک/عمومی
قرار دادید، به‌صورت اتفاقی آپلود نشوند. این دو فایل را یک‌جای امن (مثلاً پوشه‌ی رمزگذاری‌شده یا
مدیر رمز عبور) نگه دارید — اگر گم شوند، دیگر نمی‌توانید بروزرسانی امضاشده برای همان اپ منتشر کنید.

### ساخت APK امضاشده روی کامپیوتر خودتان (Android Studio)

چون `keystore.properties` همراه پروژه است، کافی است در Android Studio بزنید:
`Build > Build Bundle(s) / APK(s) > Build APK(s)` و بعد از منوی Build Variants حالت **release**
را انتخاب کنید. خروجی در `app/build/outputs/apk/release/app-release.apk` قرار می‌گیرد و آماده‌ی
نصب یا آپلود در Play Console است.

### ساخت APK امضاشده با GitHub Actions

چون فایل کیستور روی خود GitHub آپلود نمی‌شود (به‌خاطر `.gitignore`)، باید آن را جدا و به‌صورت
رمزگذاری‌شده (Secret) به ریپازیتوری بدهید:

1. در پوشه‌ی پروژه (بعد از اکسترکت زیپ)، این دستور را اجرا کنید تا کیستور به متن base64 تبدیل شود:
   ```
   base64 -w0 app/release.keystore
   ```
   (روی مک/ویندوز اگر دستور `base64 -w0` کار نکرد، از `base64 app/release.keystore` بدون `-w0` استفاده کنید.)
2. در ریپازیتوری GitHub خود بروید به: **Settings > Secrets and variables > Actions > New repository secret**
   و ۴ سکرت زیر را بسازید:
   - `KEYSTORE_BASE64` → همان متن base64 مرحله‌ی قبل
   - `KEYSTORE_PASSWORD` → رمز عبور داخل `keystore.properties`
   - `KEY_ALIAS` → `mushroom-release`
   - `KEY_PASSWORD` → همان رمز عبور (در این کیستور، رمز store و key یکسان است)
3. یک پوش جدید (یا اجرای دستی از تب Actions) انجام دهید. این‌بار علاوه بر APK دیباگ، یک
   artifact به اسم `mushroom-accounting-release-apk` هم ساخته و قابل دانلود می‌شود — همان
   نسخه‌ی امضاشده‌ی آماده برای Play Store.

### اگر می‌خواهید در Google Play منتشر کنید

- باید در [Google Play Console](https://play.google.com/console) یک حساب توسعه‌دهنده بسازید
  (هزینه‌ی یک‌بار ثبت‌نام دارد).
- فایل release را آپلود می‌کنید (یا بهتر: خروجی `.aab` بسازید به‌جای `.apk` — با دستور
  `gradle bundleRelease` یا از منوی Build Studio گزینه "Android App Bundle").
- توجه: چون این اپ صرفاً یک WebView محلی است، ممکن است سیاست‌های گوگل‌پلی درباره‌ی
  "حداقل محتوا/عملکرد بومی" را بررسی کند؛ برای استفاده‌ی داخلی/شخصی (نصب مستقیم APK روی
  گوشی‌های کارگاه) هیچ مشکلی وجود ندارد و نیازی به گوگل‌پلی هم نیست.
